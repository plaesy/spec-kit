## Patterns Learned

**Config Loading Pattern**: When config is nested in `UnifiedConfig` (e.g., `search.embedder`), must load `UnifiedConfig` first, not the sub-struct directly. The `ConfigManager[T]` reads the whole file.

**Test Coverage as Quality Gate**: Constitution makes 90% coverage non-negotiable for Technical dimension. Current state: 7/12 packages below threshold. This is a blocking finding for `/assess`.

**HTTP Fallback Pattern**: Platforms with only CLI backends need HTTP/API adapters for zero-config operation. Architecture supports this via RegistryOption pattern.
