# `/fix:marketing` command instructions

This is the **marketing**-scoped entry point into `/fix`. Follow the full protocol
defined in `/fix`, with scope fixed to **marketing**: Unsourced claims, brand inconsistencies.

Same 8-dimension scope set as `/assess:{scope}` (see `/assess`) — treat
