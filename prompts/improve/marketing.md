# `/improve:marketing` command instructions

This is the **marketing**-scoped entry point into `/improve` (Project Mode). Follow the
full protocol defined in `/improve`, with scope fixed to **marketing**: Positioning/channel/GTM practice currency.

Same 8-dimension scope set as `/assess:{scope}` (see `/assess`) — do not broaden
scope to other dimensions unless the user explicitly asks with a comma-separated
scope on `/improve` itself. Artifact Mode (a single document/Figma file/deck named
in the request) ignores dimension scope entirely — see `/improve`.
