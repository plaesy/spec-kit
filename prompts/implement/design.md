# `/implement:design` command instructions

Scope fixed to **design**: Design/component implementation.

- **Loads**: `.plaesy/instructions/assess-design.md` — apply its **Persona
  Protocol** first, then follow the full protocol in `/implement`.
- **Building new UI or reshaping existing screens?** Also load
  `.plaesy/instructions/frontend-design.md` for aesthetic direction — palette,
  typography, layout risk-taking — so the output isn't a templated default.
  `.plaesy/memory/design.md` (via `/spec:design`) is the recorded token
  source of truth; `frontend-design.md` is the taste judgment applied on top
  of it when a screen is new, not a replacement for reading the tokens first.
- **Needs a logo, avatar, or a stat/testimonial visual mid-run?** Route through
  `/create:images` — its Step 1a gates identity-bearing assets on user
  confirmation or an honest placeholder; do not fabricate one inline here.
