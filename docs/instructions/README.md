# Instructions

Plaesy's instructions now live in the skills folder. Each skill is `skills/<name>/SKILL.md`, and its supporting material is in `references/` and `assets/`.

- The list of files that `plaesy init` installs, and which ones are always loaded, is in [`skills/plaesy/assets/mapping.json`](../../skills/plaesy/assets/mapping.json).
- The skills index is in [`skills/`](../../skills/).
